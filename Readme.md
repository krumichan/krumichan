## 🐈 Current Project — TranslaCat

> 言語と日常をつなぐ個人Full-stackプロジェクト

**TranslaCat**は、翻訳、リアルタイムチャット、Webコンテンツ、音声処理、
個人の財務管理機能を一つのサービス内で提供するプラットフォームです。

### 主な開発領域

* リアルタイムの個人チャットおよびグループチャット
* 多言語UIおよびメッセージ翻訳
* ユーザープロフィールおよび画像ストレージ
* Webコンテンツの探索および翻訳支援
* 音声ファイルの処理および翻訳
* 個人・グループ家計簿
* レシートOCRおよびAI分析
* 認証、権限管理およびAPIセキュリティ
* DockerベースのデプロイおよびGitHub Actions CI/CD

## 🌱 Development Philosophy

> 良いソフトウェアは、コードだけで完成するものではありません。<br/>
> 要件、設計、ユーザー体験、テスト、運用が一つにつながっていることが重要だと考えています。

```text
Understand the problem
        ↓
Design the flow
        ↓
Build the system
        ↓
Test the behavior
        ↓
Deploy and improve
```
