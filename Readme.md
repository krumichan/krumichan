단순히 기능을 구현하는 것뿐 아니라, **사용자가 실제로 이용할 수 있는 하나의 완성된 제품으로 만들어 가는 과정**을 중요하게 생각합니다.  
単に機能を実装するだけでなく、**ユーザーが実際に利用できる一つの完成したプロダクトへ仕上げていく過程**を大切にしています。

요구사항과 화면 흐름을 정리하고, Frontend와 Backend를 설계하며, 테스트부터 배포까지 이어지는 개발을 지향합니다.  
要件や画面フローを整理し、FrontendとBackendを設計し、テストからデプロイまでつなげる開発を目指しています。

## 🐈 진행 중인 프로젝트 / 開発中のプロジェクト — TranslaCat

> 언어와 일상을 연결하는 개인 풀스택 프로젝트  
> 言語と日常をつなぐ個人フルスタックプロジェクト

**TranslaCat**은 언어학습, 번역, 실시간 채팅, 웹 콘텐츠, 음성 처리, 개인·그룹 가계부를 하나의 서비스 안에서 연결하는 플랫폼입니다.  
**TranslaCat**は、言語学習、翻訳、リアルタイムチャット、Webコンテンツ、音声処理、個人・グループ家計簿を一つのサービス内でつなぐプラットフォームです。

### 주요 개발 영역 / 主な開発領域

- **언어학습** — Writing·Listening·Speaking·Reading·Vocabulary, 문제 생성·평가·학습 이력  
  **言語学習** — Writing・Listening・Speaking・Reading・Vocabulary、問題生成・評価・学習履歴
- **실시간 채팅** — 개인·그룹 채팅과 메시지·읽음·접속 상태 관리  
  **リアルタイムチャット** — 個人・グループチャットとメッセージ・既読・接続状態の管理
- **다국어 지원** — 다국어 UI와 메시지 번역  
  **多言語対応** — 多言語UIとメッセージ翻訳
- **프로필과 스토리지** — 사용자 프로필과 이미지 저장소 연동  
  **プロフィールとストレージ** — ユーザープロフィールと画像ストレージの連携
- **웹 콘텐츠** — 콘텐츠 탐색과 번역 지원  
  **Webコンテンツ** — コンテンツの探索と翻訳支援
- **음성 처리** — 음성 파일 처리·음성 인식·번역  
  **音声処理** — 音声ファイルの処理・音声認識・翻訳
- **가계부** — 개인·그룹 가계부와 거래 관리  
  **家計簿** — 個人・グループ家計簿と取引管理
- **영수증 분석** — 영수증 이미지 인식·OCR·AI 분석과 사용자 확인 흐름  
  **レシート解析** — レシート画像認識・OCR・AI解析とユーザーによる確認フロー
- **보안** — 인증·권한 관리·API 보안  
  **セキュリティ** — 認証・権限管理・APIセキュリティ
- **배포 자동화** — Docker 기반 배포와 GitHub Actions CI/CD  
  **デプロイ自動化** — DockerベースのデプロイとGitHub Actions CI/CD

機能ごとの責務をBE・LL・CHATに分け、AIサーバーがモデル・画像・音声処理の実行を担当する構成にしています。設計や実行方法の詳細は、各リポジトリのREADMEにまとめています。

## 🌱 개발 철학 / 開発で大切にしていること

> 좋은 소프트웨어는 코드만으로 완성되지 않습니다.<br/>
> 요구사항, 설계, 사용자 경험, 테스트, 운영이 하나로 연결되어야 한다고 생각합니다.
>
> 良いソフトウェアは、コードだけで完成するものではありません。<br/>
> 要件、設計、ユーザー体験、テスト、運用が一つにつながっていることが重要だと考えています。

```text
문제 이해 / 課題を理解する
            ↓
흐름 설계 / フローを設計する
            ↓
시스템 구현 / システムを実装する
            ↓
동작 검증 / 振る舞いを検証する
            ↓
배포와 개선 / デプロイし、改善する
```
